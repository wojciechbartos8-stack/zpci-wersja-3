JavaScript – programowanie dynamicznych stron

Praktyczne szkolenie przygotowujące do tworzenia dynamicznych i interaktywnych stron internetowych z wykorzystaniem języka JavaScript.

Uczestnik poznaje podstawy programowania, obsługę modelu DOM, zdarzenia, formularze oraz sposoby modyfikowania elementów strony internetowej.

Kogo zapraszamy?

Szkolenie przeznaczone jest dla osób znających podstawy HTML i CSS, które chcą rozszerzyć swoje umiejętności o programowanie w JavaScript.

Kurs skierowany jest do przyszłych twórców stron WWW, webmasterów, pracowników działów IT oraz osób rozwijających własne serwisy internetowe.

Organizacja i metodyka

Zajęcia realizowane są w trybie indywidualnym lub grupowym. Terminy ustalane są elastycznie i dopasowywane do uczestników.

Szkolenie prowadzone jest w formie praktycznych ćwiczeń komputerowych z naciskiem na tworzenie interaktywnych elementów stron WWW.

Ramowy program szkolenia

JavaScript w dokumencie HTML

Dołączanie skryptów wewnętrznych i zewnętrznych.

Zmienne i stałe

Deklarowanie danych za pomocą let, const oraz var.

Typy danych

Teksty, liczby, wartości logiczne, tablice i obiekty.

Operatory

Operacje matematyczne, logiczne, porównania i przypisania.

Instrukcje warunkowe

Stosowanie instrukcji if, else oraz switch.

Pętle

Wykorzystanie pętli for, while, do while i forEach.

Funkcje

Tworzenie funkcji, parametry, wartości zwracane i funkcje strzałkowe.

Tablice

Dodawanie, usuwanie, filtrowanie i przetwarzanie danych.

Operacje na tekstach

Konkatenacja, szablony tekstowe i metody obiektu String.

Model DOM

Odczytywanie i modyfikowanie elementów dokumentu HTML.

Obsługa zdarzeń

Kliknięcia, zmiany pól, klawiatura i zdarzenia formularzy.

Walidacja formularzy

Sprawdzanie poprawności danych wprowadzanych przez użytkownika.

Style i klasy CSS

Dynamiczne zmienianie wyglądu elementów strony.

Programowanie obiektowe

Obiekty, właściwości, metody, klasy i konstruktory.

Break i continue

Sterowanie przebiegiem wykonywania pętli.

Interaktywne strony WWW

Tworzenie praktycznych elementów i prostych aplikacji internetowych.

Po ukończeniu szkolenia uczestnik

Uczestnik zdobywa wiedzę oraz praktyczne umiejętności umożliwiające samodzielne tworzenie interaktywnych elementów stron internetowych.

Wie

  • Do czego służy język JavaScript.
  • Jakie są podstawowe typy danych.
  • Do czego służą zmienne, funkcje, pętle i instrukcje warunkowe.
  • Czym jest model DOM dokumentu HTML.

Rozumie

  • Zasady wykonywania kodu JavaScript przez przeglądarkę.
  • Różnicę pomiędzy strukturą HTML, stylami CSS i logiką JavaScript.
  • Mechanizm zdarzeń występujących na stronie.
  • Znaczenie walidacji danych w formularzach.

Umie

  • Deklarować zmienne i wykonywać operacje na danych.
  • Stosować instrukcje warunkowe oraz pętle.
  • Tworzyć funkcje, tablice i podstawowe obiekty.
  • Pobierać i modyfikować elementy strony za pomocą DOM.

Potrafi

  • Samodzielnie stworzyć interaktywny element strony WWW.
  • Obsługiwać kliknięcia, formularze i inne zdarzenia.
  • Sprawdzać poprawność danych formularza.
  • Wykorzystać JavaScript podczas tworzenia własnej strony internetowej.
