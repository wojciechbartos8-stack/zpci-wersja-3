Szkolenie PHP i MySQL

Programowanie dynamicznych stron i aplikacji internetowych

Programowanie stron PHP + MySQL

Szkolenie PHP i MySQL przeznaczone jest dla osób, które chcą nauczyć się tworzenia dynamicznych stron internetowych oraz aplikacji wykorzystujących bazy danych.

Podczas zajęć uczestnik poznaje język PHP, obsługę formularzy HTML, komunikację z bazą MySQL, wykonywanie zapytań SQL oraz tworzenie aplikacji internetowych działających po stronie serwera.

Szkolenie ma charakter praktyczny. Uczestnik wykonuje ćwiczenia związane z tworzeniem, zapisywaniem, odczytywaniem, edytowaniem i usuwaniem danych.

Kogo zapraszamy?

Szkolenie jest przeznaczone dla osób zainteresowanych programowaniem stron WWW, tworzeniem aplikacji internetowych oraz pracą z bazami danych.

Kurs może być odpowiedni zarówno dla osób rozpoczynających naukę PHP, jak i dla osób, które posiadają podstawową wiedzę z zakresu HTML i programowania.

Organizacja szkolenia

Szkolenie prowadzone jest w praktycznej formule z wykorzystaniem przykładów i ćwiczeń programistycznych.

Program może zostać dostosowany do poziomu uczestnika oraz indywidualnych potrzeb szkoleniowych.

Kwalifikacje po ukończeniu szkolenia

Po ukończeniu szkolenia uczestnik otrzymuje potwierdzenie zdobycia wiedzy i umiejętności z zakresu programowania stron i aplikacji internetowych z wykorzystaniem PHP i MySQL.

Nazwa kwalifikacji:
Programowanie stron WWW z wykorzystaniem PHP i MySQL

Qualification:

Efekty szkolenia

  • Uczestnik zna podstawy programowania po stronie serwera w języku PHP.
  • Rozumie komunikację pomiędzy stroną WWW a bazą danych.
  • Potrafi tworzyć i przetwarzać formularze HTML.
  • Potrafi utworzyć bazę danych MySQL oraz jej podstawową strukturę.
  • Potrafi połączyć bazę danych z dynamiczną stroną internetową.
  • Potrafi wykonywać operacje CRUD.
  • Potrafi przygotować podstawowy system rejestracji i logowania użytkowników.
  • Rozumie podstawowe zasady bezpieczeństwa aplikacji internetowych.
