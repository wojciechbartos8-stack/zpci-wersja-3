Programowanie Java

Kogo zapraszamy?

Szkolenie przeznaczone jest dla osób, które chcą rozpocząć naukę programowania w języku Java.

Kurs pozwala poznać podstawowe konstrukcje języka oraz zasady programowania obiektowego. Uczestnik wykonuje praktyczne ćwiczenia i tworzy własne programy.

Termin, organizacja i metodyka szkolenia

Zajęcia organizowane są indywidualnie lub dla grup zorganizowanych.

Terminy ustalane są elastycznie i mogą zostać dopasowane do możliwości uczestników.

Szkolenie prowadzone jest przede wszystkim w formie praktycznych ćwiczeń komputerowych. Nauka obejmuje pisanie kodu, analizowanie jego działania oraz poprawianie podstawowych błędów.

Zakres szkolenia

  • Podstawy języka Java
  • Struktura programu Java
  • Zmienne i typy danych
  • Operatory
  • Instrukcje warunkowe
  • Pętle
  • Tablice
  • Metody
  • Programowanie obiektowe
  • Klasy i obiekty
  • Konstruktory
  • Dziedziczenie
  • Interfejsy
  • Obsługa wyjątków
  • Tworzenie aplikacji konsolowych
  • Podstawy pracy ze środowiskiem IntelliJ IDEA lub Eclipse

Efekty szkolenia

Po ukończeniu szkolenia uczestnik zna podstawowe zasady programowania w języku Java oraz potrafi wykorzystać je w praktycznych zadaniach.

Potrafi tworzyć proste aplikacje konsolowe, stosować programowanie obiektowe oraz pracować z klasami, obiektami, dziedziczeniem, interfejsami i wyjątkami.

Zdobyte podstawy stanowią punkt wyjścia do dalszej nauki języka Java oraz technologii wykorzystywanych przy tworzeniu bardziej zaawansowanych aplikacji.

Taksonomia efektów kształcenia

Po ukończeniu szkolenia uczestnik zdobywa wiedzę oraz praktyczne umiejętności pozwalające na samodzielne tworzenie prostych programów w języku Java i dalszy rozwój w kierunku programowania obiektowego.

Uczestnik wie

  • czym jest język programowania Java,
  • jakie są podstawowe typy danych i zmienne,
  • do czego służą operatory,
  • jak działają instrukcje warunkowe i pętle,
  • czym są tablice i metody,
  • czym jest programowanie obiektowe,
  • czym są klasy i obiekty,
  • na czym polega dziedziczenie,
  • czym są interfejsy,
  • czym są wyjątki i obsługa wyjątków.

Uczestnik rozumie

  • sposób działania podstawowych elementów programu Java,
  • zależności pomiędzy zmiennymi, typami danych i operacjami,
  • działanie instrukcji warunkowych i pętli,
  • znaczenie metod w strukturze programu,
  • znaczenie klas i obiektów,
  • zasady programowania obiektowego,
  • zasady dziedziczenia,
  • rolę interfejsów,
  • znaczenie obsługi wyjątków.

Uczestnik umie

  • tworzyć proste programy w języku Java,
  • deklarować zmienne,
  • dobierać odpowiednie typy danych,
  • stosować operatory,
  • stosować instrukcje warunkowe,
  • wykorzystywać pętle,
  • tworzyć i wykorzystywać tablice,
  • tworzyć własne metody,
  • tworzyć klasy i obiekty,
  • wykorzystywać dziedziczenie i interfejsy,
  • obsługiwać wyjątki.

Uczestnik potrafi

  • samodzielnie przygotować prostą aplikację w języku Java,
  • zaprojektować podstawową strukturę programu,
  • wykorzystać klasy i obiekty w praktycznym zadaniu,
  • zastosować zasady programowania obiektowego,
  • wykorzystać dziedziczenie oraz interfejsy,
  • obsługiwać sytuacje wyjątkowe,
  • analizować i poprawiać podstawowe błędy w kodzie,
  • rozwijać przygotowaną aplikację o kolejne funkcje,
  • samodzielnie kontynuować naukę bardziej zaawansowanych technologii Java.
Certyfikat ukończenia szkolenia
