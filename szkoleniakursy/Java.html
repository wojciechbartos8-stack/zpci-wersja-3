Programowanie Java

Kogo zapraszamy?

Szkolenie przeznaczone jest dla wszystkich osób chcących rozpocząć naukę programowania w języku Java.

Uczestnik zdobywa praktyczne umiejętności tworzenia aplikacji oraz pracy z obiektowym podejściem do programowania.

Termin, organizacja i metodyka szkolenia

Zajęcia organizowane są indywidualnie lub dla grup zorganizowanych. Terminy ustalane są elastycznie i dopasowywane do uczestnika.

Szkolenie prowadzone jest w formie praktycznych ćwiczeń komputerowych, nastawionych na zdobycie praktycznych umiejętności programistycznych.

Zakres szkolenia

  • Podstawy języka Java
  • Zmienne i typy danych
  • Operatory
  • Instrukcje warunkowe
  • Pętle
  • Tablice
  • Metody
  • Programowanie obiektowe
  • Klasy i obiekty
  • Dziedziczenie
  • Interfejsy
  • Obsługa wyjątków
  • Tworzenie aplikacji konsolowych
  • Praca w środowisku IntelliJ IDEA lub Eclipse

Efekty szkolenia

Po ukończeniu szkolenia uczestnik potrafi samodzielnie tworzyć aplikacje w języku Java, zna zasady programowania obiektowego oraz jest przygotowany do dalszej nauki technologii Java wykorzystywanych przy tworzeniu aplikacji desktopowych i internetowych.

Taksonomia efektów kształcenia

Po ukończeniu szkolenia uczestnik zdobywa wiedzę i praktyczne umiejętności pozwalające na samodzielne tworzenie programów w języku Java oraz dalszy rozwój w kierunku programowania obiektowego.

Uczestnik wie

  • czym jest język programowania Java,
  • jakie są podstawowe typy danych i zmienne,
  • do czego służą operatory, instrukcje warunkowe i pętle,
  • czym są tablice i metody,
  • czym jest programowanie obiektowe,
  • czym są klasy i obiekty,
  • na czym polega dziedziczenie i wykorzystanie interfejsów,
  • czym są wyjątki i do czego służy ich obsługa,
  • jakie są podstawowe zasady tworzenia aplikacji konsolowych.

Uczestnik rozumie

  • sposób działania podstawowych elementów programu Java,
  • zależności pomiędzy zmiennymi, typami danych i wykonywanymi operacjami,
  • sposób działania instrukcji warunkowych i pętli,
  • zasady wykorzystania metod w programie,
  • znaczenie klas i obiektów w programowaniu obiektowym,
  • zasady dziedziczenia,
  • znaczenie interfejsów w projektowaniu programu,
  • znaczenie obsługi wyjątków dla poprawnego działania aplikacji.

Uczestnik umie

  • tworzyć proste programy w języku Java,
  • deklarować zmienne i dobierać odpowiednie typy danych,
  • stosować operatory i instrukcje warunkowe,
  • wykorzystywać pętle do wykonywania powtarzalnych operacji,
  • tworzyć i wykorzystywać tablice,
  • tworzyć własne metody,
  • tworzyć klasy i obiekty,
  • wykorzystywać dziedziczenie i interfejsy,
  • obsługiwać wyjątki w programie.

Uczestnik potrafi

  • samodzielnie przygotować prostą aplikację w języku Java,
  • zaprojektować strukturę programu wykorzystując klasy i obiekty,
  • zastosować zasady programowania obiektowego w praktycznym zadaniu,
  • wykorzystać dziedziczenie oraz interfejsy,
  • prawidłowo reagować na sytuacje wyjątkowe występujące podczas działania programu,
  • analizować i poprawiać podstawowe błędy w kodzie,
  • rozwijać przygotowaną aplikację o kolejne funkcje,
  • samodzielnie kontynuować naukę bardziej zaawansowanych technologii Java.
