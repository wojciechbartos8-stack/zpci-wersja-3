HTML + CSS - Projektowanie stron WWW

Kogo zapraszamy?

Szkolenie przeznaczone jest dla wszystkich osób chcących rozpocząć naukę tworzenia stron internetowych z wykorzystaniem technologii HTML i CSS.

Kurs skierowany jest zarówno do osób początkujących, jak i osób chcących zdobyć podstawowe umiejętności potrzebne w pracy webmastera.

Termin, organizacja i metodyka szkolenia

Zajęcia organizowane są indywidualnie lub dla grup zorganizowanych. Terminy ustalane są elastycznie i dopasowywane do uczestników.

Szkolenie prowadzone jest w formie praktycznych ćwiczeń komputerowych, podczas których uczestnik tworzy własne strony internetowe.

Zakres szkolenia

  • Podstawy języka HTML
  • Struktura dokumentu HTML
  • Znaczniki semantyczne HTML5
  • Formatowanie tekstu i elementów strony
  • Tworzenie linków i nawigacji
  • Wstawianie grafik i multimediów
  • Tworzenie tabel
  • Tworzenie formularzy internetowych
  • Podstawy języka CSS
  • Selektory, klasy i identyfikatory CSS
  • Kolory, tła, obramowania i cienie
  • Model pudełkowy CSS
  • Układ strony z wykorzystaniem Flexbox
  • Układ strony z wykorzystaniem CSS Grid
  • Responsywne projektowanie stron WWW
  • Zapytania medialne CSS
  • Podstawy dostępności stron internetowych
  • Podstawy optymalizacji SEO
  • Porządkowanie struktury plików witryny
  • Publikacja strony w Internecie

Po ukończeniu szkolenia uczestnik

Uczestnik zdobywa wiedzę i praktyczne umiejętności pozwalające na samodzielne projektowanie, modyfikowanie i publikowanie prostych stron internetowych.

Wie

  • Do czego służą języki HTML i CSS.
  • Jak zbudowany jest dokument HTML.
  • Jakie są podstawowe znaczniki HTML5.
  • Jakie metody służą do publikowania stron internetowych.

Rozumie

  • Różnicę pomiędzy strukturą HTML a wyglądem definiowanym w CSS.
  • Zasady semantycznej budowy strony.
  • Działanie modelu pudełkowego CSS.
  • Znaczenie responsywności i dostępności strony internetowej.

Umie

  • Tworzyć dokumenty HTML od podstaw.
  • Formatować wygląd elementów za pomocą CSS.
  • Dodawać tekst, grafiki, linki, listy i formularze.
  • Korzystać z układów Flexbox i CSS Grid.

Potrafi

  • Samodzielnie zaprojektować prostą stronę internetową.
  • Dostosować stronę do komputerów, tabletów i telefonów.
  • Modyfikować istniejący kod HTML i CSS.
  • Przygotować pliki i opublikować stronę w Internecie.
